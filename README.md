# team-07
[프로젝트 소개]
본 프로그램은 주요 배달 플랫폼인 '요기요'에 등록된 특정 상권 내 외식업체들의 리뷰 수와 평점(고객 만족도) 간의 상관관계를 통계적으로 분석하고 시각화하는 프로그램입니다.
부산대학교 상권 주위 중 배달 수요가 가장 높은 3대 업종(치킨, 피자/양식, 중국집)을 조사 대상으로 삼아 각 가게의 가게명과 리뷰 수, 별점을 조사했습니다. 이후 리뷰 수와 별점이 어떤 상관관계를 가지는지를 추정하여 배달 시장 내에서의 '리뷰 수'와 '별점'의 관계를 탐구하고자 합니다.

[팀원]
202542131 박민주, 202642150 양대선, 202642155 이동운

[실행 방법]
1. 라이브러리 설치
파이썬 터미널을 열고 필요한 외부 라이브러리(streamlit, pandas, numpy, beautifulsoup4, selenium, plotly)들을 설치한다.
2. 프로그램 구동
터미널에 streamlit run [파일명].py라고 입력 후 실행을 기다린다.
3. 데이터 분석 수행
브라우저 화면이 뜨면 대상 주소지를 확인하고 '통합 크롤링 시작' 버튼을 누른다.
이때 '이상치 제거'를 하고 싶다면 '이상치 제거'버튼을 누른다.(리뷰 수 30개 이하 가게는 조사하지 않음)
이후, 외부 크롬 브라우저 3개가 켜지며 3개 항목의 데이터 수집이 동시에 진행된다. 수집 완료 후 중복이 제거된 데이터프레임 표, 상관관계 산점도 그래프가 출력된다. 
결과 데이터(CSV,엑셀파일) 및 대화형 그래프(HTML)를 개별 다운로드할 수 있다.

streamlit, Pandas, NumPy, BeautifulSoup4, Selenium, Plotly,
